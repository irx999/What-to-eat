# What to eat · 今天吃什么

一个无需构建、无需后端的中文随机选餐页面，使用原生 HTML/CSS、JavaScript 和本地 Zepto。

## 本地运行

在项目目录执行：

```sh
python -m http.server 8001 --bind 127.0.0.1
```

浏览器打开 http://localhost:8001。也可直接打开 `index.html`，或将静态文件部署到 GitHub Pages 等静态托管服务。

## 使用

- 点击“开始”滚动候选项，再点击“停”确定结果。
- 点击标题中的餐次，切换早饭、午饭、晚饭。
- 空闲时可切换食物分类；滚动期间分类和餐次暂时锁定。
- 支持 Tab、Enter 和空格操作；焦点不在交互控件上时，空格可开始或停止。
- 页面切到后台时自动停止并保留当前结果，返回后可再次点击“换一个”。
- 跟随系统“减少动态效果”设置，关闭装饰动画并降低滚动频率。

## 维护

- `js/app.js`：食物、趣味文案和选餐逻辑。
- `css/style.css`：界面与动画。
- `index.html`：页面结构与现有百度统计配置。

早饭沿用独立早餐列表（“非正常人类”除外）。“龙湖天街”目前仍是“没写”占位项，需补充真实餐厅；本次未更改原有餐厅内容。
